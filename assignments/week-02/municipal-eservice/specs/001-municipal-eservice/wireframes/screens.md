## เส้นทางคลิกหลัก

- Citizen: เข้าสู่ระบบ → ลงทะเบียน (ผู้ใช้ใหม่) → คำขอของฉัน → ยื่นคำขอ 3 ขั้น → ชำระจำลอง → รายละเอียดคำขอ → เอกสาร → public verify
- Officer: คิวงาน → รับเรื่อง → ตรวจเอกสาร / ขอแสดงเลขบัตรเต็มพร้อมเหตุผล → ดำเนินการตามบริการ → ออกเอกสาร
- Head: รออนุมัติ → รายละเอียดคำขอ → อนุมัติ / ไม่อนุมัติ → ผู้ออกเอกสารดำเนินการ
- Executive / Auditor: ตัวกรอง → KPI หรือเหตุการณ์ → ตัวอย่างส่งออก
- Admin: บริการและ SLA → วันหยุด → ผู้ใช้และบทบาท
