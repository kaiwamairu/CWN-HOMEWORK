# GIF เวอร์ชัน 2 — การเคลื่อนไหวต่อเนื่อง

[เปิดดูทั้งสามฉาก](index.html) · [รุ่นก่อน](../civic-motion-20261116/index.html)

แก้อาการวัตถุเปลี่ยนตำแหน่งและเกิดภาพซ้อนจากรุ่นก่อน ซึ่งนำ keyframes ที่ AI วาดต่างกันมาละลายภาพคั่น
รุ่นนี้ใช้ไฟล์ภาพนิ่งชุด 1A / 2A / 3A ที่ผู้ใช้เลือกเป็นต้นฉบับโดยตรง
ขยับเฉพาะจุดเล็ก ๆ ด้วย sampling offsets ที่ต่อเนื่องและเป็นคาบ ไม่มีการสลับภาพฉากที่ AI วาดใหม่

- ภาพหลัก 448×560, 25 fps, 125 เฟรม, วนซ้ำรอบละ 5 วินาที
- พรีวิวในแชต 160×200, 20 fps, 100 เฟรม, วนซ้ำรอบละ 5 วินาที
- 1A: ใบไม้และธงไหวเล็กน้อย
- 2A: มือและปากกาขยับเบา ๆ
- 3A: มือเช็กเอกสารและกระดาษขยับเบา ๆ
- อาคาร ใบหน้า ฉากหลัง และส่วนที่อยู่นอกขอบเขตการเคลื่อนไหวถูกตรึงไว้
- ภาพที่จุดเริ่มลูปและครบหนึ่งคาบตรงกัน และเส้นทางการขยับมีความต่อเนื่องข้ามรอยต่อ

การขยับแบบนี้เหมาะกับฉากหลังเว็บที่เคลื่อนไหวเบา ๆ ไม่ใช่การแสดงท่าทางตัวละครเต็มรูปแบบ
ไฟล์รุ่นก่อนเก็บแยกไว้ให้เทียบ ไม่มีการเขียนทับภาพต้นฉบับหรือ GIF รุ่นก่อน
