# GIF เวอร์ชัน 3 — เพิ่มระยะขยับให้มองเห็น

[เปิดดูทั้งสามฉาก](index.html)

รุ่นก่อนมีระยะขยับมือประมาณ 2 px ในไฟล์เต็ม และต่ำกว่า 1 px ในพรีวิว จึงมองเห็นยากแม้กำลังเล่น
รุ่นนี้เพิ่มแอมพลิจูด โดยยังใช้ภาพต้นฉบับเดียวกับเส้นทางการเคลื่อนไหวที่ต่อเนื่อง

- 1A ธงและใบไม้: sampling offset สูงสุดประมาณ 12 px ที่ขนาด 448×560
- 2A มือกรอกฟอร์ม: ประมาณ 8 px
- 3A มือกับเอกสาร: ประมาณ 7 px
- 25 fps, 125 เฟรม, วนรอบละ 5 วินาที
- พรีวิวขนาดย่อ 20 fps, 100 เฟรม และแสดงทีละฉากขนาดใหญ่ขึ้น
- พรีวิวอ่าน GIF ด้วย ImageDecoder และแสดงหมายเลขเฟรมที่วาดจริงเมื่อเบราว์เซอร์รองรับ
- มี native GIF fallback, ปุ่มเล่น/หยุด และรองรับการตั้งค่าลดการเคลื่อนไหว

ส่วนที่อยู่นอกขอบเขตเคลื่อนไหว เช่น ใบหน้า อาคาร และฉากหลัง ถูกตรึงจากต้นฉบับ
ภาพเป็นการขยับเฉพาะส่วนของภาพนิ่ง เหมาะกับฉากหลังเว็บ ไม่ใช่การสร้างท่าทางตัวละครใหม่
