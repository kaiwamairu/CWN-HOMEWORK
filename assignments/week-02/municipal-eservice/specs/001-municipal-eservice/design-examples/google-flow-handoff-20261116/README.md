# ภาพต้นฉบับและ Prompt สำหรับ Google Flow

ชุดภาพที่ผู้ใช้เลือก: **1A / 2A / 3A**
ภาพ PNG ต้นฉบับ 1122×1402 พิกเซล คัดลอกโดยคง byte เดิม ไม่มีการย่อ บีบอัดใหม่ หรือดัดแปลงภาพ

1. เปิด Google Flow และสร้างหรือเลือกโปรเจกต์
2. ที่ช่อง prompt เลือก **Video → Frames** แล้วใส่ภาพที่ต้องการใน **Add start frame**
3. คัดลอก prompt ของภาพนั้นจากหน้า `index.html` หรือไฟล์ `1A-prompt.txt`, `2A-prompt.txt`, `3A-prompt.txt`
4. เลือกโมเดลที่บัญชีคุณมีโควตาใช้งาน และความยาวที่มีให้ เช่น 8 วินาที ทดลองครั้งละหนึ่งผลลัพธ์ก่อน
5. ตรวจการครอบภาพก่อนสร้าง โดยเฉพาะหาก Flow ใช้ 9:16 เพราะภาพต้นฉบับเป็น 4:5 อย่าตัดมือ เอกสาร หรือทางเข้าอาคาร
6. หากต้องการทดสอบ loop และมีช่อง **Add end frame** สามารถลองใส่ภาพเดียวกันเป็นภาพท้ายได้ โดยเฉพาะฉาก 1A การกำหนดภาพท้ายช่วยควบคุมท่าจบ แต่ไม่รับประกัน loop ที่ไร้รอยต่อ
7. ดาวน์โหลดและเก็บวิดีโอ MP4 ต้นฉบับที่ความละเอียดสูงสุดที่บัญชีมีให้ก่อน เพื่อนำไปใช้บนเว็บหรือแปลง GIF ภายหลัง

ไฟล์ `index.html` มีภาพและปุ่มคัดลอก prompt สำหรับแต่ละฉาก
ไฟล์ `PROMPTS.md` รวม prompt ทั้งสาม และ `google-flow-images-prompts.zip` รวมภาพและเอกสารสำหรับส่งต่อ

Prompt เน้นกล้องนิ่งและการเคลื่อนไหวต่อเนื่อง โดยไม่ให้โมเดลเปลี่ยนฉากหรือสไตล์ภาพเดิม
ผลลัพธ์จริงขึ้นกับโมเดลและการตั้งค่าในบัญชีของผู้ใช้

อ้างอิงวิธีใช้ Frames: [Google Flow Help](https://support.google.com/flow/answer/16353334?co=GENIE.Platform%3DDesktop&hl=en)
