เปิด `index.html` ด้วย browser ได้ทันที ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องรัน server
หน้าเว็บทำงานออฟไลน์ โดยเก็บเนื้อหา CSS JavaScript และ SVG อยู่ในไฟล์

- เอกสารฉบับเต็ม31ฉบับ: ชุด Spec Kit/ผลทบทวน/วิธีรัน21ฉบับ และโจทย์ต้นทาง10ฉบับ
- User flow10เส้นทาง คลิกแต่ละขั้นดูบทบาท หน้าจอ สถานะ กติกา และ TC
- เปรียบเทียบ3บริการ พร้อมตัวอย่างคำนวณค่าธรรมเนียมตามค่าตั้งต้น
- ค้นหาข้อความในเอกสารและงาน78รายการ พิมพ์เอกสารเป็น PDF หรือเก็บ HTML
- `flows/` มี SVG ทุกเส้นทาง; `userflows.md` เป็นรายการอ้างอิง
- `guide.zip` รวมคู่มือ ภาพ SVG และต้นฉบับ Markdown สำหรับส่งต่อ

`preview.html` เป็นฉบับแสดงในแชต มีเอกสาร21ฉบับและทุกflow ภายใต้512KB
ฉบับเต็ม `index.html` มีโจทย์ต้นฉบับเพิ่มเติมครบทั้งหมด

## แก้ไขและสร้างใหม่

```powershell
python guide/build.py
```

รันจากโฟลเดอร์ week2_student ใช้ Python standard library เท่านั้น
แก้การแสดงผลที่ `template.html`; แก้แผนภาพที่ `flow_content.py`
เอกสารดึงจากไฟล์จริงในโครงการ ไม่เปลี่ยน source oracle

นี่คือคู่มือออกแบบ ไม่ใช่แอปยื่นคำขอที่สร้างตาม78งาน ไม่มีการอ้างว่า51TCของแอปรันแล้ว
ThaiD การชำระ และลายเซ็นยังเป็นตัวจำลองตามโจทย์


## หน้าตาที่เลือก

เลือก C / เมืองแห่งบริการ: ภาพอาคารราชการ จุดบริการ และวัตถุประจำบริการ
เมนูเขียวป่า การ์ดครีมโปร่งนุ่ม แสงและเงาคงที่ ไม่มีการไล่ตามเมาส์
เปิด `design-preview.html` ดูประชาชน/คิวเจ้าหน้าที่ หรืออ่าน Design system,
15 หน้า / 4 layout และ design token จากส่วนเอกสารในคู่มือ
`design-tokens.json`, `design-tokens.css`, `design-assets.json` และภาพใน `design-assets/` แนบใน ZIP ด้วย
